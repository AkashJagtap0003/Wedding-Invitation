# Akash & Akshada Wedding Invitation

Mobile-friendly Maratha wedding story invitation. Static website for GitHub Pages.

Upload `index.html` and the `assets` folder to the root of your GitHub repository. Enable Pages: Settings → Pages → Deploy from branch → `main` → `/ (root)`.

Details currently included: Akash Jagtap & Akshada Kharade; 7 February 2027; Punyai Garden, Kashti Road, Mandavgan Pharata; Maps link supplied by couple.

Wedding time is still a placeholder. Edit the `wedding` object in index.html to add the time and update calendarStart/calendarEnd accordingly.
